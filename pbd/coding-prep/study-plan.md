# 4-Week Study Plan (full plan, ~120 hours)

**Schedule:** weekdays ~3 h, weekend days ~7.5 h (20 × 3 h + 8 × 7.5 h = 120 h). Days 1–5 are Monday–Friday and Days 6–7 are the weekend. If you start on another day, keep the order and shift the long days onto your weekend.

**Covers:** all 17 pattern modules, all 86 must-dos, all 6 practical exercises, all 36 disguised drills, and 4 mock interviews, with redos spaced out after misses.

**Problem estimates** (including review): Easy ~20 min, Medium ~40, Hard ~65. ★ = top-35 problem. Links: `practice-tracker.md`.

---

## How every session works

1. **Warm-up (10 min):** write one template from memory and check it against that module's **Template cheat sheet**. Rotate through the modules you've studied.
2. **Learn (when scheduled):** read At a glance → Core idea → Signals → Disguises. Then, for each template, type it out and attempt its worked examples before opening the solutions.
3. **Solve:** follow the problem protocol in `23-practice-plan-and-review.md`:
   - classify first (`Signal → Pattern → Template`)
   - plan in ≤ 5 min, code in ≤ 15 min, talk out loud
   - stuck at 25 min → one hint, then re-implement from scratch after reading the solution
4. **Log (10–15 min):** update `practice-tracker.md` (✅ / 🟡 / ❌) and write the **missed signal** for anything not ✅.
5. **Redo slot:** on days that have one, redo blind any ❌/🟡 problem from **3 days ago** and **7 days ago**.

## Readiness check (Day 28)

From module 23. You're ready when:
- [ ] All 86 must-dos solved blind (misses redone after 7 days)
- [ ] All 6 practical exercises implemented from scratch, timed
- [ ] All 36 drills classified; misclassified ones coded and re-classified correctly
- [ ] Any template written from memory in under 5 minutes
- [ ] Unseen mediums: ≥ 8/10 in under 25 minutes, right pattern within 5 minutes
- [ ] Mocks: rubric ≥ 3 in every dimension

If some boxes are unchecked, keep going between interview rounds: 1–2 unseen mediums a day, plus redos and one mock a week.

---

## If you fall behind

- **Don't skip redos or logging.** They're where the learning sticks.
- **Shift, don't cram:** push the day's remaining problems into the next weekend.
- **Trim in this order:** extra drill coding beyond the misses (Day 27) → mock #4 → module 17's non-starred hards (329, 312), moved to after the plan.
- **Ahead of schedule?** Add 1–2 optional problems from your weakest module's practice ladder, or an extra mock.
