Each pattern has **5 must-do problems** (6 for DP foundations), chosen to cover its main sub-variants, with one hard where it matters. Do every must-do before any optional problem. Optional problems are for depth in your weaker or most important patterns. Each module's full Practice ladder has even more.

- **Must-dos:** 86 LeetCode problems + 6 practical exercises + module 22 drills
- **★ = top 35:** do these first if you only have about 2 weeks
- Use the problem protocol in `23-practice-plan-and-review.md`: classify first (Signal → Pattern → Template), timebox to 25 min, log the signal you missed, redo misses after 3, 7, and 21 days.

**Compared with Blind 75:** 43 of the Blind 75 are must-dos here. The other 32 are all in the course as optional problems (mostly easy tree/string/DP warm-ups and some premium graph problems). The 43 must-dos that aren't in Blind 75 cover patterns Blind 75 skips: monotonic stack, binary search on the answer, multi-source BFS, Dijkstra/Bellman-Ford/MST, union-find, backtracking, knapsack/state-machine/interval DP, greedy, and heaps.
